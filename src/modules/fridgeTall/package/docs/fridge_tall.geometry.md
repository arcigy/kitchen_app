# Geometry

Overall dimensions: 600 x 1916 x 600 mm

## Parameter Effects

- `width`: Fridge width changes carcass span, appliance niche width and both door front widths.
- `height`: Fridge height changes side panels, niche height and overall front stack height.
- `depth`: Fridge depth changes carcass depth, niche depth envelope and top/bottom panel footprint.
- `boardThickness`: Board thickness changes carcass stock thickness and the resulting internal niche width.
- `backThickness`: Back thickness changes the rear panel stock and usable internal appliance depth.
- `frontThicknessMm`: Front thickness changes both door front boards and the selected front material thickness.
- `freezerDoorHeightMm`: Freezer door height changes the split between the upper freezer front and lower fridge front.
- `fridgeDoorGapMm`: Door gap changes the visible spacing between the upper and lower fridge fronts.
- `fridgeWidthMm`: Fridge niche width changes appliance opening width and side clearances inside the carcass.
- `fridgeHeightMm`: Fridge niche height changes appliance opening height and remaining door proportions.
- `fridgeDepthMm`: Fridge niche depth changes appliance fit and the rear clearance envelope.
- `plinthHeight`: Plinth height changes support geometry and shifts the usable appliance niche upward.

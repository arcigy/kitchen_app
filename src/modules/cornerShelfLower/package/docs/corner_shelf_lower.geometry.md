# Geometry

Overall dimensions: 1000 x 720 x 1000 mm

## Parameter Effects

- `width`: corner_shelf_lower width changes carcass span, top/bottom panel width and drawer/front clear width.
- `height`: corner_shelf_lower height changes side panels, front stack allocation and internal vertical clearances.
- `depth`: corner_shelf_lower depth changes side panel depth, drawer box depth and back panel footprint.
- `boardThickness`: Board thickness changes panel stock thickness and all dependent internal clear dimensions.
- `drawerCount`: Drawer count changes number of drawer fronts, runner sets and drawer box assemblies.
- `drawerFrontHeights`: Drawer front heights redistribute the visible front stack and drawer aperture geometry.
- `frontGap`: Front gap changes revealed spacing between stacked fronts and side/top/bottom front edges.
- `worktopThicknessMm`: Worktop thickness reduces effective carcass height when the module uses a worktop.
- `plinthHeight`: Plinth height changes support geometry and usable carcass height for floor-mounted modules.

# Geometry

Overall dimensions: 900 x 720 x 560 mm

## Parameter Effects

- `width`: Width changes carcass span, top and bottom panel width, shelf width and the exported flap or door-front widths.
- `height`: Height changes total module height and therefore side panel height, back panel height and front opening height.
- `depth`: Depth changes side panel depth, shelf depth, top and bottom footprint and back panel footprint.
- `boardThickness`: Board thickness changes carcass stock thickness and all dependent internal clear dimensions.
- `backThickness`: Back thickness changes the rear panel stock and the usable internal shelf depth.
- `frontThicknessMm`: Front thickness changes the exported flap front or both hinged door fronts.
- `shelfCount`: Shelf count changes the number of internal shelves and the shelf-support hardware count.
- `shelfThickness`: Shelf thickness changes the stock used for each internal shelf board.
- `shelfAutoFit`: Shelf auto-fit switches between equalized shelf spacing and manually defined shelf gaps.
- `shelfGaps`: Shelf gaps manually redistribute the internal shelf spacing when auto-fit is disabled.
- `doorSystem`: Door system switches between a single lift-up flap front and a split pair of hinged door fronts.
- `doorOpen`: Door open changes preview state only; it does not change manufacturable board dimensions.
- `liftUpComponentId`: Lift-up component selection changes the exported lift-up hardware set when doorSystem is flap_up.
- `hingeComponentId`: Hinge component selection changes the exported hinge hardware set when doorSystem is double_hinged.
- `hangingBracketComponentId`: Hanging bracket selection changes the exported wall bracket hardware set.
- `shelfSupportComponentId`: Shelf support selection changes the exported shelf-support hardware count for internal shelves.

# Geometry

Overall dimensions: 800 x 700 x 560 mm

## Parameter Effects

- `width`: Shelf width changes carcass span, top and bottom panel width, shelf width and both door front widths.
- `height`: Height changes the total module height including worktop and shifts the derived carcass height.
- `heightCarcass`: Height carcass changes side panel height, door height and the internal shelf stack envelope.
- `depth`: Depth changes side panel depth, shelf depth, top and bottom footprint and back panel footprint.
- `boardThickness`: Board thickness changes carcass stock thickness and all dependent internal clear dimensions.
- `shelfThickness`: Shelf thickness changes the stock used for each internal shelf board.
- `backThickness`: Back thickness changes the rear panel stock and the usable internal shelf depth.
- `shelfCount`: Shelf count changes the number of internal shelf boards and the vertical shelf layout.
- `shelfAutoFit`: Shelf auto-fit switches between equalized shelf spacing and manually defined shelf gaps.
- `shelfGaps`: Shelf gaps manually redistribute the internal shelf spacing when auto-fit is disabled.
- `frontThicknessMm`: Front thickness changes both swing door boards and the selected front material thickness.
- `hingeCountPerDoor`: Hinge count per door changes the quantity of hinge assemblies exported for both swing doors.
- `worktopThicknessMm`: Worktop thickness reduces effective carcass height while keeping total module height fixed.
- `plinthHeight`: Plinth height changes support geometry and reduces the visible door height and internal shelf envelope.
